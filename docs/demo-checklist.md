# Pre-Demo Checklist

- [ ] Confirm README on the default branch describes the demo scope
- [ ] Confirm `docs/demo-brief.md` is in place on the default branch
- [ ] Confirm `.github/workflows/ci.yml` exists, triggers on every push, and echoes a hello line
- [ ] Confirm the `chore/tidy-notes` branch is created off the default branch
- [ ] Verify the pull request opens and shows up in the repo's open pull requests
- [ ] Check whether an Actions run kicked off for `chore/tidy-notes`
